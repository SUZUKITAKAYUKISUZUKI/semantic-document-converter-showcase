# Synthetic Demo

This demo illustrates a source-faithful transformation:

```text
Synthetic input
      ↓
Structured document interpretation
      ↓
Source-faithful Markdown
```

The source page combines fictional prose, a short code sample, a simple node-edge diagram, and a formula. The expected output preserves each type with an appropriate Markdown representation.

- [View the synthetic source](synthetic_source.png)
- [View the illustrative expected output](synthetic_output.md)

The demo uses entirely synthetic material so the public repository contains no copyrighted source-document content.
